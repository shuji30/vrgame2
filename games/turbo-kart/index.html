ハンコン / FFB 設定

      
「割り当て」を押してから、使いたいハンドル・ペダル・ボタンを操作してください。別々の USB 機器（ホイールベース・ペダル・サイドブレーキ・シフター）を組み合わせられます。

            はじめての設定（ハンコンの手ごたえ＝FFB を出すには、PC に「デバイスブリッジ」を入れます）
            
⬇ デバイスブリッジをダウンロード（ZIP）

            
    
              
  1. ダウンロードした ZIP を右クリック →「すべて展開」。中の start.bat をダブルクリック（Python などのインストールは不要）。黒い画面に「デバイスブリッジ起動」と出たら、閉じずにそのまま
    2. 
              
  2. この画面の上の表示が「ブリッジ接続中」になればつながっています。下の「右へ」「左へ」でハンドルが動くか確認（逆に回るときは「力の向きを反転」をオン）
    3. 
              
  3. 毎回の起動が面倒なら install-autostart.bat を 1 回実行（Windows の起動時に自動で起動）
    4. 
            

            
「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。ウイルス対策ソフトに止められたら、そのフォルダを許可してください。詳しくは ZIP の中の README.txt を見てください。

ブラウザで直接接続（WebHID・インストール不要）

      
PC の Chrome / Edge で使えます。最初に 1 回だけ機器を選んで許可すると、次回からは自動でつながります。
        ホイールベース・ペダル・サイドブレーキ・シフターを 1 台ずつ追加してください。標準の FFB 規格（HID PID）に対応したハンコン
        （CAMMUS・MOZA・Simagic・Simucube など）は、ブラウザだけで FFB も出せます。Fanatec・Thrustmaster・Logitech の FFB にはデバイスブリッジが必要です。
