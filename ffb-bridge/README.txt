TURBO KART VR デバイスブリッジ（FFB 用）使い方
================================================

ブラウザのゲームから、ハンコンの FFB（フォースフィードバック）を出すための小さなプログラムです。
Windows 10 / 11 の PC で使います。Python などのインストールは不要です。

■ はじめて使うとき
1. ダウンロードした ZIP を右クリック →「すべて展開」で、好きな場所に展開する
   （ZIP の中から直接は起動できません。必ず展開してください）

2. 展開したフォルダの「start.bat」をダブルクリックする
   黒い画面に「デバイスブリッジ起動」と出たら準備完了です。この画面は閉じずにそのままにしてください。
   ※「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
   ※ ウイルス対策ソフトに止められたら、このフォルダを「許可」してください。

3. Chrome / Edge でゲームを開き、「ハンコン / FFB 設定」に「ブリッジ接続中」と出ていれば OK。
   「右へ」「左へ」のテストボタンで力が出るか確かめてください。
   逆に回るときは「力の向きを反転」をオンにします。

■ 毎回起動するのが面倒なとき
「install-autostart.bat」を 1 回だけダブルクリックすると、Windows にログオンしたとき
自動で（最小化して）起動するようになります。やめるときは「uninstall-autostart.bat」。

■ 力の強さ
ダイレクトドライブは強力です。最初はゲームの「全体の強さ」を低めにして、
ハンドルから手を離さずに試してください。
ブリッジ側の上限は、コマンドプロンプトで start.bat --max 0.5 のように起動すると変えられます（既定 0.8 = 80%）。

■ うまく動かないとき
・「FFB デバイスなし」: ハンコンのメーカーのドライバー（CAMMUS Software、Fanatec Driver など）が
  入っているか確認してください。
・テストボタンと逆に回る: ゲームの設定で「力の向きを反転」を切り替えてください。
・ハンコンを替えたら: ゲームの設定で強さと向きを合わせ直してください。
・ほかのサイトでも使いたい: origins.txt にそのサイトの URL を 1 行ずつ書いてください。

■ 安全のための仕組み
・この PC の中（127.0.0.1）だけで待ち受け、許可したゲームのサイトからしか接続できません。
・ゲームから 0.25 秒指示が来なければ、自動で力を 0 にします。
