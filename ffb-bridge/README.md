# デバイスブリッジ（TURBO KART VR 用）

PC で動かす小さな常駐プログラムです。ブラウザだけではできない次の 2 つを担当します。

1. **FFB（フォースフィードバック）の出力**：ゲームが計算した力を、SDL2 経由でハンコンへ出力します。DirectInput の FFB を使うので、メーカーの PC 用ドライバーが入っていれば **Fanatec / Thrustmaster / CAMMUS / Logitech / MOZA / Simagic** など一般的な FFB ハンコンで動きます。
2. **入力の中継**：ブラウザの Gamepad API は同時に 4 台までしか扱えません。VR ヘッドセット（Pimax など）に枠を取られると、ホイールベースやペダルが見えなくなります。ブリッジはすべてのジョイスティック（ホイールベース・ペダル・USB サイドブレーキ・H シフター）を読み、ゲームへ送ります。

## 使い方

1. [Python 3.10 以上](https://www.python.org/downloads/) をインストール
2. **おすすめ**: `install-autostart.bat` を 1 回だけダブルクリック。以後は Windows にログオンすると、画面を出さずに自動で起動します（解除は `uninstall-autostart.bat`）
   - 手動で起動したいときは `start.bat`（ウィンドウを閉じると停止）
3. PC の Chrome / Edge でゲームを開き、「ハンコン / FFB 設定」で「ブリッジ接続中」と出れば OK

自動起動では FFB の最大出力を 30%（`--max 0.3`）にしています。強くしたいときは、スタートアップのショートカット（`TurboKart Device Bridge`）のプロパティで数値を変えてください。

## オプション

```bat
start.bat --max 0.5          :: FFB の最大出力を 50% に（ダイレクトドライブは低めから）
start.bat --device Fanatec   :: FFB を出すデバイスを名前で指定
start.bat --no-ffb           :: 入力の中継だけ行い、FFB は出さない
start.bat --list             :: 認識しているデバイスの一覧
start.bat --allow-origin https://example.com   :: 接続を許可するゲームの URL を追加
```

## 安全のための仕組み

- 出力は `--max`（既定 80%）で頭打ちにします。
- 力が急に変わらないよう、変化の速さを制限します（ダイレクトドライブで急に振られないように）。
- ゲームから 0.25 秒指示が来なければ、自動で力を 0 にします（ブラウザが固まったとき・閉じたとき）。
- `127.0.0.1` でのみ待ち受け、許可したゲームの URL からの接続だけを受け付けます。ほかのサイトがハンコンを動かすことはできません。

## うまく動かないとき

- **「FFB デバイスなし」**：ハンコンのドライバー（Fanatec Driver、Thrustmaster Drivers、CAMMUS Software など）が入っているか確認してください。メーカーのソフトがハンコンを独占していると FFB を出せないことがあります。
- **ポートが使用中**：既定のポートは 18765 です（8765 は Pimax のクライアントが使っています）。
- **力の向きが逆**：ゲームの「ハンコン / FFB 設定」で「力の向きを反転」をオンにしてください。
